Eres un modelo nuevo continuando trabajo de otro modelo que fue interrumpido.

1. Lee AGENTS.md y PROGRESS.md.
2. Ejecuta `git status`, `git diff` y `git log --oneline -10`.
3. Compila el proyecto para comprobar que el último estado funciona.
4. Dime en pocas líneas: qué fase y paso estaba en curso, qué quedó hecho, qué quedó a medias y cuál es el siguiente paso.
5. Si PROGRESS.md y el código no coinciden, dímelo y corrige PROGRESS.md.
6. Espera mi confirmación y luego continúa con el siguiente paso siguiendo las reglas de continuidad.
