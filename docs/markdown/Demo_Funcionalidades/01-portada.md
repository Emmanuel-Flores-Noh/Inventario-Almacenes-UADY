## Propósito

Este documento reúne ejemplos reales de las funcionalidades del template:
Markdown, tablas, bloques de código, imágenes locales, fórmulas LaTeX y
diagramas Mermaid. Sirve como demostración visual y como prueba de regresión
para comprobar que el flujo completo sigue generando un PDF correcto.

El contenido está dividido en varios archivos Markdown. Cada archivo comienza
en una página nueva, lo que también demuestra el soporte multidocumento.

> **Cómo usar esta demo:** genera el PDF y revisa que todos los elementos de la
> lista de comprobación del último apartado aparezcan correctamente.

## Contenido

1. Portada y metadatos.
2. Funcionalidades de Markdown.
3. Fórmulas matemáticas con LaTeX.
4. Diagramas Mermaid.
5. Imágenes y recursos locales.
6. Pruebas y verificación.

## Resultado esperado

Al finalizar la compilación se debe generar un PDF llamado
`Demo_Funcionalidades.pdf` con todas las secciones, los diagramas convertidos a
imagen y las fórmulas renderizadas como vectores SVG.
